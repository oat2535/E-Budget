1. สิ่งที่จำเป็นต้องติดตั้งก่อนใช้งาน (Prerequisites & Driver Setup)
--------------------------------------------------------------------------------
หากเปิด Power Query แล้วพบ Error:
"DataSource.MissingClientLibrary: Please install Npgsql version 4.0.10.0 or earlier."

สาเหตุ:
Power BI Desktop และ Microsoft Excel บน Windows ใช้ .NET Data Provider ชื่อ "Npgsql"
ในการเชื่อมต่อฐานข้อมูล PostgreSQL โดย Microsoft กำหนดว่าต้องใช้เวอร์ชัน 4.0.10 เท่านั้น
(เวอร์ชันใหม่กว่านี้ เช่น v5, v6, v7, v8 ทาง Power BI ยังไม่รองรับ)

วิธีติดตั้ง Npgsql 4.0.10 (ทำเพียงครั้งเดียวในเครื่องที่ใช้งาน):
1. ดาวน์โหลดตัวติดตั้ง Npgsql 4.0.10 (Official Release):
   - ลิงก์ดาวน์โหลดตรง: https://github.com/npgsql/npgsql/releases/download/v4.0.10/Npgsql-4.0.10.msi
   - หรือเข้าผ่านหน้ารวม: https://github.com/npgsql/npgsql/releases/tag/v4.0.10 แล้วเลือกดาวน์โหลด Npgsql-4.0.10.msi
2. ดับเบิลคลิกเปิดไฟล์ Npgsql-4.0.10.msi เพื่อเริ่มติดตั้ง
3. กด Next ไปจนถึงหน้าต่าง "Custom Setup"
   *** สำคัญมาก (จุดที่มักพลาดกัน) ***
   - มองหารายการ "Npgsql GAC Installation" (ค่าเริ่มต้นจะมีกากบาทสีแดง X)
   - คลิกที่ไอคอนกากบาทสีแดงหน้า Npgsql GAC Installation
   - เลือกเป็น "Will be installed on local hard drive" (ไอคอนจะเปลี่ยนเป็นรูปไดรฟ์สีขาว)
4. กด Next -> กด Install -> รอติดตั้งจนเสร็จ แล้วกด Finish
5. *** ปิดโปรแกรม Power BI Desktop หรือ Excel ทั้งหมด แล้วเปิดขึ้นมาใหม่ ***
   (เพื่อให้โปรแกรมโหลด Driver จาก Windows GAC เข้าสู่ระบบ)

กรณีพบ Error: "The remote certificate is invalid according to the validation procedure"
--------------------------------------------------------------------------------
สาเหตุ:
เกิดจาก Power BI ตั้งค่าพยายามเข้ารหัสลับ SSL (Encrypt connections) อัตโนมัติ แต่ฐานข้อมูล
PostgreSQL ภายในวงแลน (192.168.99.39) ใช้ใบรับรองภายใน (Self-Signed Certificate) หรือไม่ได้ติดตั้ง Public SSL CA
ทำให้ Windows ฟ้องว่าใบรับรองไม่ถูกต้องตามขั้นตอนตรวจสอบ

วิธีแก้ไข (ทำง่ายๆ ภายใน 10 วินาที):
1. ในโปรแกรม Power BI Desktop ไปที่เมนู:
   - "ไฟล์" (File) -> "ตัวเลือกและการตั้งค่า" (Options and settings) -> "การตั้งค่าแหล่งข้อมูล" (Data source settings)
   (หากใช้ Excel: ไปที่แท็บ "ข้อมูล" (Data) -> "รับข้อมูล" (Get Data) -> "การตั้งค่าแหล่งข้อมูล" (Data Source Settings))
2. คลิกเลือกรายการแหล่งข้อมูล:
   "192.168.99.39:5435;tlph"
3. คลิกปุ่ม "แก้ไขสิทธิ์..." (Edit Permissions...) ที่ด้านล่าง
4. ในหน้าต่างแก้ไขสิทธิ์:
   - มองหาช่อง "เข้ารหัสลับการเชื่อมต่อ" (Encrypt connections)
   - *** เอาเครื่องหมายถูกออก (Uncheck) ***
5. คลิก "ตกลง" (OK) แล้วคลิก "ปิด" (Close)
6. กลับมาที่หน้า Power Query หรือหน้ารายงาน แล้วคลิกปุ่ม "ลองอีกครั้ง" (Retry) หรือ "รีเฟรช" (Refresh)
   -> ข้อมูลจะดึงขึ้นมาได้สำเร็จทันที 100%

ทางเลือกสำรอง (กรณีเครื่องติดสิทธิ์ IT ไม่สามารถลง MSI ได้ แต่มี ODBC Driver อยู่แล้ว):
--------------------------------------------------------------------------------
หากในเครื่องมี "PostgreSQL Unicode(x64)" ODBC Driver ติดตั้งอยู่:
- สามารถเปิด "ตัวแก้ไขขั้นสูง" (Advanced Editor) ใน Power Query
- เลื่อนลงไปบรรทัดล่างสุด เปลี่ยนจาก:
    Source = PostgreSQL.Database(...)
  เป็น:
    Source = Odbc.Query("Driver={PostgreSQL Unicode(x64)};Server=" & ServerHost & ";Database=" & DatabaseName & ";", SqlQuery)

4. วิธีการใช้งานตัวกรองปีงบประมาณ (Budget Year) และสาขา (Branch)
--------------------------------------------------------------------------------
ตัวกรองถูกออกแบบตามหลัก Best Practice โดย Pushdown เงื่อนไขไปกรองที่ฐานข้อมูล PostgreSQL โดยตรง
ช่วยให้ดึงข้อมูลได้รวดเร็ว ประหยัด RAM และ Bandwidth เครือข่ายสูงสุด

วิธีที่ 4.1: ปรับแก้ในตัวแปร M Code โดยตรง (ง่ายและรวดเร็ว)
- ดับเบิลคลิกเปิด "ตัวแก้ไขขั้นสูง" (Advanced Editor)
- สังเกตบรรทัดที่ 23-24:
    BudgetYear = try pBudgetYear otherwise 2025,
    BranchCode = try pBranchCode otherwise "ALL",
- สามารถปรับแก้ค่าได้ดังนี้:
    * กรองปี 2026 ทุกสาขา:
        BudgetYear = 2026,
        BranchCode = "ALL",
    * กรองปี 2025 เฉพาะสำนักงานใหญ่ (HO):
        BudgetYear = 2025,
        BranchCode = "HO",
    * ดึงข้อมูลทั้งหมดทุกปีและทุกสาขา:
        BudgetYear = "ALL",
        BranchCode = "ALL",

วิธีที่ 4.2: สร้างพารามิเตอร์ใน Power BI (Manage Parameters)
- ใน Power Query Editor คลิกปุ่ม "จัดการพารามิเตอร์" (Manage Parameters) -> "พารามิเตอร์ใหม่" (New Parameter)
- พารามิเตอร์ที่ 1:
    * Name: pBudgetYear
    * Type: Decimal Number หรือ Text
    * Current Value: 2025
- พารามิเตอร์ที่ 2:
    * Name: pBranchCode
    * Type: Text
    * Current Value: ALL  (หรือใส่รหัสสาขาเช่น HO, PM, CA)
- เมื่อกดบันทึก โค้ด M จะตรวจจับและผูกกับ Parameter ทั้งสองตัวนี้ให้อัตโนมัติทันที
  ผู้ใช้งานสามารถเปลี่ยนปีหรือสาขาผ่านหน้าต่างพารามิเตอร์ของ Power BI ได้สะดวก
